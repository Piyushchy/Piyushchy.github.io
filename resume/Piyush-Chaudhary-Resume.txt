PROJECTS

namestorage: Self-Hosted Cloud Drive (Python, WebRTC, WebSockets, STUN/ICE, Tailscale Funnel, OIDC, systemd, Linux, pytest) - github.com/Piyushchy/namestorage
- Private drive on my own Ubuntu laptop behind CGNAT: the agent makes only outbound connections (no port forwarding), and the browser connects peer-to-peer over an encrypted WebRTC data channel, so no server stores or relays files.
- NAT traversal with ICE and Google's public STUN server. Published the Python WebSocket signaling server as a public wss:// endpoint with Tailscale Funnel (no VPS, static IP or open port); it relays only SDP setup messages.
- Security: server-side verification of Google OIDC ID tokens (signature, issuer, audience, expiry) against an email allow-list on both server and agent; origin check; rate limiting; single-use HMAC tickets (120 s, replay-rejected) bound to the DTLS fingerprint; path-traversal confinement; systemd hardening.
- One-command installer and management CLI. 79 automated tests (pytest), including a real WebRTC session.
