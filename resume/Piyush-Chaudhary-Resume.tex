\section*{PROJECTS}
\noindent\textbf{namestorage: Self-Hosted Cloud Drive} (Python, WebRTC, WebSockets, STUN/ICE, Tailscale Funnel, OIDC, systemd, Linux, pytest)\hfill \href{https://github.com/Piyushchy/namestorage}{github.com/Piyushchy/namestorage}\par
\begin{itemize}
  \item Private drive on my own Ubuntu laptop behind CGNAT: the agent makes only outbound connections (no port forwarding), and the browser connects peer-to-peer over an encrypted WebRTC data channel, so no server stores or relays files.
  \item NAT traversal with ICE and Google's public STUN server. Published the Python WebSocket signaling server as a public wss:// endpoint with Tailscale Funnel (no VPS, static IP or open port); it relays only SDP setup messages.
  \item Security: server-side verification of Google OIDC ID tokens (signature, issuer, audience, expiry) against an email allow-list on both server and agent; origin check; rate limiting; single-use HMAC tickets (120 s, replay-rejected) bound to the DTLS fingerprint; path-traversal confinement; systemd hardening.
  \item One-command installer and management CLI. 79 automated tests (pytest), including a real WebRTC session.
\end{itemize}
