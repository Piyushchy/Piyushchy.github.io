Pause to select frames and edit them. Drag either track left or right to shift it against the other. Top track: base GIF. Bottom track: overlay GIF.

Both tracks work the same way. Tick the boxes on either track (Shift+tick selects a range within a track); the last frame you tick or click is shown in the panel above. Blank hides that GIF’s frame (it looks faded); Skip removes that moment from the final GIF entirely (struck through in red on both tracks). Each button needs all ticked frames to be in the same state and flips to Unblank / Unskip. Hold last frame appears when only the last frame of a track is ticked and the other track runs longer: it repeats that frame until both end together. Empty gaps export as transparent (or just the other GIF).
